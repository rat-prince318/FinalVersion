## 文件修改优先级

### 高优先级

1. `src/i18n/resources/en.ts` - 添加新翻译键
2. `src/i18n/resources/zh.ts` - 添加对应中文翻译
3. `src/components/FileUploader.tsx` - 大量未翻译文本
4. `src/components/TwoSampleMeanCI.tsx` - 核心组件
5. `src/components/TwoProportionCI.tsx` - 置信区间组件

### 中优先级

1. `src/components/PowerFunction.tsx` - 功效函数组件
2. `src/components/TwoSampleDataGenerator.tsx` - 数据生成器
3. `src/components/DataInputPanel.tsx` - 数据输入面板
4. `src/components/DataGeneratorContainer.tsx` - 数据生成容器

## 风险评估

* 低风险：仅修改文本内容，不影响业务逻辑

* 需要确保翻译键名统一，避免重复定义

* 注意保持翻译的专业性和一致性

## 验证方法

1. 运行 `npm run build` 确保项目能正常构建
2. 在中文模式下检查所有界面文本正确显示为中文
3. 在英文模式下检查所有界面文本正确显示为英文
4. 测试语言切换功能正常工作

## 修改前后对比

### 修改前（中文模式）

* 大量混合中英文文本

* 按钮、标签、说明等仍显示英文

* 用户体验不统一

### 修改后（中文模式）

* 所有界面文本均为中文

* 翻译符合专业术语规范

* 用户体验统一且友好

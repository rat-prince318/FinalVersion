# Statistical Analysis Tool

一个面向统计分析与教学演示场景的 Web 应用，帮助用户从数据输入、分布生成到统计推断和可视化结果，完成一条完整的分析流程。

在线体验：https://rat-prince318.github.io/FinalVersion/

## 项目定位

这个应用把常见的统计分析任务整合到一个交互式界面中，适合用于：

- 学习和教学演示统计概念
- 快速进行描述性统计和推断分析
- 对样本数据进行可视化探索
- 进行简单的实验设计与样本量评估

## 统计分析工具板块
- **基本统计量计算**：均值、标准差、中位数、偏度、峰度等
- **置信区间估计**：单样本均值、双样本均值、比例、配对数据的置信区间
- **参数估计**：最大似然估计(MLE)和矩估计(MOM)
- **假设检验**：支持多种假设检验方法
- **拟合优度检验**：检验数据是否符合特定分布
- **样本量计算**：根据功效和效应量计算所需样本量

## 核心功能

### 1. 数据输入与数据管理
- 支持手动输入数据、CSV 文件上传以及模拟数据生成
- 支持单样本、双样本和配对样本数据处理
- 支持保存、加载和删除历史数据集
- 支持多数据集合并分析，便于对比和综合推断

### 2. 描述性统计分析
- 自动计算均值、标准差、中位数、最小值、最大值
- 提供偏度、峰度等分布特征指标
- 可快速判断数据是否具有明显的偏态或异常特征

### 3. 统计推断与检验
- 提供置信区间估计：单样本均值、双样本均值、比例、配对数据
- 支持常见的假设检验流程
- 包含参数估计模块：最大似然估计（MLE）与矩估计（MOM）
- 支持拟合优度检验，帮助判断数据是否符合特定分布假设

### 4. 可视化分析
- 提供概率分布可视化
- 支持直方图、QQ 图等统计图表展示
- 可将分析结果和数据形态直观呈现，提升理解效率

### 5. 统计功效与样本量分析
- 支持功效函数分析与样本量计算
- 可以根据显著性水平、效应量和样本量评估检验能力

## 特色亮点

- 端到端流程：从数据录入到统计推断，一站式完成
- 面向教学与实践：适合课堂演示、实验分析和快速探索
- 可视化友好：图表与统计结果结合，便于理解和展示
- 多种输入方式：兼顾手动输入、文件上传和模拟生成
- 支持多语言界面：内置中英文切换

## 技术架构

### 技术栈
- 前端框架：React 18
- 类型系统：TypeScript
- 构建工具：Vite
- UI 组件：Chakra UI
- 图表库：Recharts
- 数学计算：mathjs
- 文件处理：xlsx
- 国际化：i18next

### 架构设计

项目整体分为三个层次：

1. 用户界面层
   - 由页面组件和功能组件构成，负责数据输入、结果展示和交互控制

2. 业务逻辑层
   - 统计计算、假设检验、区间估计和样本量分析等逻辑集中在工具函数和组件中实现

3. 数据与状态层
   - 使用 React 状态管理承载当前数据集、历史数据和分析参数

### 目录结构

```text
src/
├── components/      # 各类统计分析与可视化组件
├── pages/           # 应用主页面
├── utils/           # 统计计算与数据生成工具函数
├── i18n/            # 多语言配置与资源
├── App.tsx          # 应用入口
└── main.tsx         # React 挂载入口
```

## 快速开始

### 环境要求
- Node.js >= 14
- npm 或 yarn

### 安装

```bash
npm install
```

### 开发运行

```bash
npm run dev
```

### 构建发布

```bash
npm run build
```

### 部署到 GitHub Pages

```bash
npm run deploy
```

## 使用建议

建议的使用顺序如下：

1. 选择数据输入方式：手动输入、上传文件或生成模拟数据
2. 进行描述性统计和分布观察
3. 根据需要选择置信区间、假设检验、参数估计或样本量分析
4. 结合图表结果进行解释与展示

## 说明

本应用主要面向统计学习、教学演示和快速分析场景，适合在浏览器中直接使用。实际科研或正式报告中，仍建议结合具体统计方法和领域背景进行判断。
